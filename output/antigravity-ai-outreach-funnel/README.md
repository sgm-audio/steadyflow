# Antigravity AI Outreach Funnel

Portable copy and systems package derived strictly from the supplied YouTube transcript.

## Purpose

Use this package as an importable content module for an outreach, lead-enrichment, CRM, or funnel-review project. It contains copy assets, targeting signals, automation logic, and the original source transcript.

## Package contents

- `FUNNEL_ASSETS.md` — landing-page hooks, two-minute VSL, and three-email sequence.
- `AUTOMATION_BLUEPRINT.md` — lead-enrichment, routing, review, and measurement logic.
- `integration-manifest.json` — machine-readable metadata, tags, stages, fields, and compliance gates.
- `source/pasted-text.txt` — the supplied raw transcript.

## Core positioning

Do not chase random AI gigs. Select a validated, durable service; identify buyers with visible problems; create proof before outreach; and pursue a first client using a clear acquisition path.

The central mechanism is the **Validated AI Business Scorecard**:

1. Ease to start
2. Speed to first client
3. Evidence of market demand
4. Competitive opportunity
5. Long-term business potential

## Integration notes

1. Import `integration-manifest.json` into the parent project as a reference schema.
2. Map the listed lead signals and fields to the parent CRM.
3. Load the email copy as drafts only.
4. Require human approval before any outbound message is sent.
5. Replace CTA placeholders with real destinations only after review.

## Evidence and compliance status

- All authority and income figures are **claims made in the transcript**, not independently verified facts.
- The source describes a 60-day first-client target; it is not a guarantee.
- Scarcity language must not be used unless a real deadline or capacity limit exists.
- No outreach has been sent and no automation has been activated by this package.
- A human must review targeting, consent, suppression status, claims, and message content before sending.

## Suggested review order

1. Validate the offer and audience fit.
2. Verify or remove authority claims.
3. Confirm the real CTA and fulfillment path.
4. Approve lead-source and compliance rules.
5. Run a small, manually reviewed pilot before enabling automation.
