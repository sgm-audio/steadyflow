# SteadyFlow — Chrome Web Store Listing

## Short Description (132 chars max)
AI-powered Shopify store analysis. Understand positioning, pricing, SEO, and product mix in one click.

## Detailed Description
SteadyFlow gives Shopify store owners and e-commerce analysts instant AI-powered insights about any Shopify store.

**How it works:**
1. Navigate to any Shopify store
2. Click the SteadyFlow extension or use the right-click menu
3. Get AI-powered analysis: product positioning, pricing strategy, SEO gaps, and competitive insights

**Features:**
- One-click analysis from any Shopify product or collection page
- Context menu integration — right-click any Shopify page
- Dashboard with stored insights and history
- Multi-store support
- Secure auth via Supabase

**Privacy:**
SteadyFlow only accesses page content when you explicitly analyze a store. We never track browsing history. Page data is transmitted securely to our API for analysis only. See our full privacy policy at [URL].
